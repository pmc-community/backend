# Intro
This repo contains the code for production-ready backend servers. The code is for a node based Hono server and for an FastAPI Py server.

# Middleware
The backend servers contains all important middleware plugins necessary to deploy your server(s) in production

# How it works
Fork, clone or download, edit your particular data (in .env), add routes to `\routes` folder as per the examples, test and deploy.

# Routes
To configure a new route, simply write its code in `\routes` as shown in the examples. Then restart the server, that's all.
